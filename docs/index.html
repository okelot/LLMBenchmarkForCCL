Headnote — how it works

Each model is given only a case name (and citation) and asked to produce a structured brief — facts, issue, decision, reasons, and ratio decidendi — as JSON. No case text is provided, so the task probes the model's actual knowledge of Canadian jurisprudence.

Every model is reached through a single OpenRouter endpoint, so results are directly comparable. The model's brief is compared section-by-section against a human-written brief using sentence-embedding cosine similarity (all-mpnet-base-v2), with long passages chunked and mean-pooled.

Human briefs are sourced from public Supreme Court of Canada case summaries. A score near 1.0 means the model's wording is semantically close to the human brief; lower scores flag missing, wrong, or invented content.

Similarity measures semantic closeness, not legal correctness — a fluent but wrong brief can still score moderately. Read it as a comparative signal across models, not a verdict on any single answer.
